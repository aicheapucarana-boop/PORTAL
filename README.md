# App do Portal do Membro – AIChE Apucarana

Página que mostra o Portal do Membro em tela cheia, com a logo do AIChE como ícone ao salvar na tela inicial.

1. Abra `gerar-icones.html` no computador, escolha a logo e baixe os 4 ícones.
2. Em `index.html`, troque `COLE_AQUI_O_LINK_DO_PORTAL` pelo link do portal (termina em `/exec`).
3. Suba todos os arquivos neste repositório e ative o GitHub Pages (Settings > Pages > Branch: main).
